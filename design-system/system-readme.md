**每一笔都是一次选择：从逻辑、功能、表现里造字，一眼抓住，小处留记忆点。**

一张图不是一幅画，是几个新造的字。字是一笔一笔厚颜料写成的，铺在微微泛黄的宣纸上。完整的规矩在「设计宪法」一节（`DESIGN.md`，版本 2.13）；本页是给 agent 用的速查。冲突时的顺序：用户当次点名 > 讲解类作品的能懂优先和可读性底线 > 设计宪法 > 别的技能自带的视觉规范 > agent 自己的审美。

## 理念：每一处细节都答得出来

- 每一处细节都要答得出背后是哪一条理念，小到一个圆角。答不出就不加。
- 存在主义：一笔就是一次选择，不修饰；几个里选一个，选中靠形不靠颜色；定下来的事盖一方印。
- 人文关怀：假设每个读者都可能色弱、有 ADHD。任何信息都不只靠颜色；三秒内知道大概在讲什么。
- 小处也要有记忆点：平凡事用写大事的规格写；彩蛋最后才加。
- 要么极空（一个字，大片空白），要么极繁（满满一页字，杂而不乱）；没有不上不下的中间状态。界面和正文永远不用极繁。

## 写字：先造字，能不用文字就不用

- 意思先交给造的字。每写一行文字先问：盖住它，图还说得明白吗？说得明白就删。
- 造字有来路：具体的逻辑、功能、表现 → 造字六法（常用象形、指事、会意）→ 元素。画它在做什么，不画它长什么样。
- 人：一个圆点是头，一笔连续的弧线是身子；不画腿，不画脸。转身、走开这类有方向的动作，只有主角戴一顶民国礼帽。
- 物：一到三笔，或负形：一块厚颜料里刮出空白，颜料是满的，字是空的。
- 字上不贴标签；图的 `alt`、无字按钮的 `aria-label` 写全意思。
- 功能信息照常保留：坐标轴、类别名、单位、图例、流程箭头、操作名称、任务要的结论。
- 抒情文案像《史记》：只摆事实，短句，不贴箭头，不下结论，不用感叹号和口号。每件作品开头一行题记（`tiji` 样式），写纪年、人或事和签号，例：`二〇一七年六月　Vaswani 等八人　第乙签`。结尾停在一个动作或一个字上。
- 样板字在资产组 `signs`，用组件 Sign 放进页面。

## 颜色：一个主色加墨

- 每件作品只有一个主色 `c`，从十二支签 `sign-jia` … `sign-chou` 里抽一支，和内容无关，和上一件不同，题记里写签号。默认 `c` = `sign-yi`。没有固定的品牌色。
- `c` 每屏只给最要紧的那一个：那个人、那个点、最高的那条数据、落款的印、这一屏唯一的主要按钮。其余全是墨：`ink`、`ink-2`、`ink-3`。
- 选中用墨，不用主色。错误用删除线加一句怎么办；成功用一句平话；禁用用一笔主色斜杠。
- 分类靠直接贴的文字、形状、线型、深浅或单字标记；图例不看颜色也读得懂；说明文字不写「红格」「绿线」。
- 底面一律宣纸：`paper` 平涂，网页上由 bundle.js 现算纤维和云纹叠上去。纸上不再加别的纹理和渐变；放在纸上的图和画布都透明底，没有白块。
- 只做浅色。深色系统下照样用宣纸。
- 小面四级：`s-sunken` 把几样东西收成一组；`s-0` 就是纸；`s-raised` 能拖动、能点开的一块；`s-overlay` 弹窗、下拉、提示，配 `shadow-overlay`。影子只给浮层，别的高低靠深浅。
- 遮罩 `scrim` 只表示下面不能操作。状态层在面上叠一层墨：`st-hover`、`st-press`、`st-drag`。
- 可读性底线：正文和小字对背景至少 4.5:1，按纸上最深处算，`ink-3` 是最淡的小字色；24px 以上的大字和必要的图形至少 3:1；控件里必须看懂的部分对相邻颜色至少 3:1。`line` 只做分隔，不承载信息。

## 字体和排版：退后

- 中文标题 `t`（站酷小薇），正文 `b`（思源宋体），普通英文 `e`（Cormorant Garamond 斜体），题记、代码、标识符、数字 `m`（JetBrains Mono）。公式用 STIX Two Text。全部来自 Google Fonts，bundle.css 已引好；中英混排按片段分别用字体。
- 不把要紧的字加粗，把不要紧的字调淡。字重一律 400。
- 正文 `body`：`fs-body` 16.5px，`lh-body` 1.9，颜色 `ink-2`，最宽 `measure`，段距 `space-para`，不缩进，一段不超过三行。要紧的句子换 `ink`，每屏不超过两句。
- 标题放大不加粗：`h1` 3.1rem，`h2` 1.6rem，`h3` 1.15rem，`h4` 比正文还小。标题上方空白至少是段距两倍。每屏一个主角，一屏不超过五种文字样式。
- 引文 `quote` 是正文里最大的字。列表不用圆点，用小号序号。链接不变色，下面一条细线。
- 不用下划线、斜体、全大写做强调。

## 版面

- 桌面旁批：5:3 双栏，栏距 `space-gutter`。正文放左栏，右栏放当场核对的账、字和小注（`small`，`ink-3`）。章节之间空 `space-section`。640px 以下并成一栏，手机 390px 宽不横向滚动，两侧留 `space-side`。
- 优先不被框束缚。分隔先用留白加一笔厚颜料，或一整块颜料里刮出纸沟，或大小不同的颜料块错开并被边缘裁切；不做等高等宽的平均格子。
- 圆角只有两种：`radius-0`（一切块和按钮）和 `radius-dot`（圆点）。
- 除小字外都有厚度：线是刮刀笔触，块是厚颜料，进度是拉笔。正文、日志和小数字保持平的。
- 幻灯片 `slide-w`×`slide-h`，安全边距 `slide-safe`，标题 `slide-title`，正文 `slide-body`，最小 `slide-min`；每页一个字，字说不全才加一句话。文档 A4，页边 `doc-margin`，正文 `doc-body` 思源宋体，行距 `doc-lh`。

## 控件：两类六套，每处只用一套

| 套 | 类名 | 组件 | 用在 |
|---|---|---|---|
| 甲 刮字块 | `k1` | ScrapeBlock | 主要操作、讲解页舞台 |
| 乙 一笔托字 | `k2` | StrokeUnder | 成组的选项，几个里选一个 |
| 丙 颜料字 | `k3` | PaintText | 颜料块、舞台、画布旁的行内小操作 |
| 丁 点线 | `k4` | DotLine | 正文和页脚里的行内小操作 |
| 戊 彩铅圈 | `k5` | PencilRing | 讲解页里能来回切的选项 |
| 己 印头 | `k6` | SealHead | 保存、标记完成 |

- 主要 `class="p"`：颜料换成 `c`，一屏最多一个，方印那一屏不放。
- 选中 `aria-pressed="true"`：靠形状和深浅，不靠颜色。
- 禁用 `disabled`：一笔主色斜杠压在字底下，bundle.js 自动加、自动去。
- 按下：压进纸里，100ms 下沉 3–4px，黏 70ms，500ms 回来。
- 触控高度不低于 44px。焦点是 1px `ink` 点线外框。开关是一条线一个点（Switch）；输入框和下拉只有一条下划线。
- 状态是一条 1px 的线和一个 15px 的点（Status），不用转圈和骨架屏。页面底部是方印落款（Seal）。数据图用拉笔（BrushBars），主色只给最大值，图下配原始表。

## 动效：颜料的物理

- 动起来像颜料在纸上：抹、写、压、落、刮、挪、退、数、换、晕，都由 bundle.js 的 `window.FF` 提供（`FF.smear`、`FF.stamp`、`FF.flip`、`FF.count`、`FF.swap`……）。
- 一律不弹，不许只有淡入淡出。回应要快（按下 100ms），内容要慢（抹开 1500ms）。
- 一屏最多一个内容的自动动作；超过 5 秒的自动动画都能停；`prefers-reduced-motion` 时直接显示终态。
- 时长和曲线写在 bundle.css 的 `:root` 上：`--t-press` 100ms、`--t-hold` 70ms、`--t-press-min` 170ms、`--t-return` 500ms、`--t-hover` 300ms、`--t-exit` 280ms、`--t-release` 380ms、`--t-move` 520ms、`--t-smear-s` 600ms、`--t-smear` 1500ms；曲线 `--e-out`、`--e-exit`、`--e-drop`、`--e-move`、`--e-pull`；两头 `--t-limp`、`--t-poise`、`--t-burst`、`--e-limp`、`--e-burst`。不手抄数值。

## 伙伴和彩蛋

- 伙伴只在长页导航和彩蛋里出现，正文和数据图里不放：白龙（资产组 `partners`）、龙娘和大肥鱼（`nav`）、小肥（`nav/xiaofei.js`）。像素和油彩形象保留原色，不算主色。
- 彩蛋三类：小概率路过；加载、空页面、出错时探头；藏在细微处（点某个字三下，点印三下）。所有伙伴共用一个出场位，一屏最多一只。

## 用这套系统

- 网页：先载入 bundle.css 和 bundle.js（它们引好了字体、宣纸、六套按钮、动效和分层母版），在 `:root` 上把 `--c` 换成这件作品抽到的签。
- 完整模板、长页导航、审阅页模板、构建脚本和其他出口（文档、演示、界面、图、动态、表格、画布）在 GitHub 仓库 `chaoRookie/feifei-ism`。
- 交付时对照设计宪法 §12 自查，逐项写「已实测 / 只静态检查 / 不适用」。代码里不写注释。
