# 肥肥主义

一句话：**用造字的办法，以厚涂为笔，写平常的事。** 画面是几个新造的字：人是一个圆点加一笔弧线，物是一到三笔，或者一块厚颜料里刮出空白（负形），全部平面、厚颜料；一个主色加墨（十二支签抽一支），微微泛黄的宣纸；正文退后，按钮是一小团颜料、要紧时抹到字底下，落款一方印。要么极空，要么极繁。淡漠、疏离、书生气，有一点小小的不对劲。

意思先交给造的字，能不用文字，就不用文字：一条锁链，人就知道大概在讲安全；三个由小到大的圆，人就知道大概是三种模型（宪法 §3.0）。

## 开工前必读

读 `references/DESIGN.md`。冲突时的优先级：用户当次点名 > 讲解类作品的能懂优先和可读性底线 > 设计宪法 > 其他技能自带的视觉规范 > 你的默认审美。其他技能照用它们的方法和流程，视觉一律换成肥肥主义。

## 怎么做一个网页

给论文做讲解页时，先用 [jiepou 仓库](https://github.com/chaoRookie/jiepou) 的 `paper-playground` 技能。这类作品能懂优先，图形跟着内容走，不必有造字和一笔人（宪法 §7.7）。

1. 先想内容：每一节发生的是什么小事，用什么字来写（宪法 §3）。每写一行文字先问：盖住它，图还说得明白吗？说得明白就删（宪法 §3.0）。
2. 复制 `templates/page.html` 当起点：题记、旁批布局、退后的排版、颜料按钮、一个点的状态、拉笔图表、方印落款、字的抹开、幻灯片、三类彩蛋都写好了。
3. 需要新的字，把笔画逐条写好交给图像模型（宪法 §9.2 有固定提示词），验收后用 `python3 scripts/sprite.py cutout 原图.png 输出.webp --size 1400` 抠底。
4. 素材用 `__ASSET:strokes/st0.webp__` 这样引用 `assets/` 里的图；自己的图放一个目录，用 `__FIG:文件名__` 引用。
5. 长页面把 `templates/nav.html` 贴到末尾，章节写 `<section data-t="章名">`，最多 8 个（宪法 §7.6）。
6. 构建：`python3 scripts/build.py 源文件.html 输出.html --figs 你的图目录`。独立网页加 `--standalone`；要嵌进别的页面或平台，用默认输出。
7. 只需要配色时，`templates/tokens.css` 是 token；`--c` 是这件作品的主色，从宪法 §5.1 的十二支签抽一支。

## 素材

| 目录 | 内容 |
|---|---|
| `assets/strokes/` | st0~st5，六条中性灰的真实刮刀笔触。代码沿路径拉，再染成任何颜色 |
| `assets/signs/` | 样板字（唱歌、转身、传话、记号、走开、人群、锁链、三个圆）和负形样板（`neg_helix.webp`，双螺旋）。可复用，也可当给图像模型的参考图；负形用 `sprite.py dye` 换签 |
| `assets/partners/` | 白龙的像素雪碧图，只用于彩蛋，一行 25 帧 |
| `assets/btn/` | 按钮用的墨色厚颜料：`dab*` 12 团，一头圆鼓一头拖尾；`slab*` 4 块长颜料，墨色和浅色各一套，做颜料块按钮，样式在 `templates/slab-button.css` |
| `assets/paper/` | 宣纸。网页铺 `xuan_fiber`、`xuan_cloud` 两张贴图（模板已接好）；幻灯片、PDF、PPTX、静态图用一整张 `xuan_sheet.webp` 垫底。`scripts/make_paper.py` 能重新生成，需要 SciPy |
| `assets/nav/` | 导航用的油彩龙娘、大肥鱼，每位六帧，从站着到成一摊；小肥封在 `xiaofei.js` 一个文件里，整只使用 |

sprite.py 和 make_paper.py 需要 Pillow、NumPy 和 SciPy。
