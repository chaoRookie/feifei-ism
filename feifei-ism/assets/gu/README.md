# gu：取形的原料

宪法 §2.4「自己定义的中式」要的原始意象放这里：甲骨文、金文、族徽、青铜纹样、山海经刻本插图。这里放的是原料，不是成品；取来的形照宪法 §3 的来路走：先想它具体的逻辑、功能、表现，再用造字六法变成元素。
