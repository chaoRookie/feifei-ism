# 肥肥主义 · 设计宪法

版本 2.9。适用于所有视觉产出：网页、幻灯片和 PPTX、图表、PDF 和文档、视频动画、作品集网站，以及 agent 与人共建的一切界面。

## 0. 优先级

1. 用户在当次对话里的点名（别的风格或交付格式，就照点名的来）。
2. 能懂。精读论文、讲解这类靠交互帮人弄懂东西的作品，看懂排在最前（§7.7）。所有作品都要守可读性底线（§5.3）。
3. 本宪法。
4. 外部技能自带的视觉规范。它们的讲解方法和流程照用，视觉以本宪法为准。
5. agent 自己的默认审美。

## 1. 一句话

**用造字的办法，以厚涂为笔，写平常的事。**

一张图不是一幅画，是几个新造的字。字是一笔一笔厚颜料写成的。写的多半是一件很小的事。

意思先交给造的字，能不用文字，就不用文字（§3.0）。

认得出来靠的是这套写法，不靠哪个颜色，也不靠哪样固定的东西。主题换了，颜色换了，写法不变。

## 2. 观念

来自两种文风。

### 2.1 《史记》的笔法

| 笔法 | 在作品里 |
|---|---|
| 寓论断于序事 | 插画和抒情文案只摆事实，不贴箭头，不写结论，不喊口号，让人自己看出来 |
| 开篇先记时 | 每件作品有一行小题记：纪年、人或事。例：`二〇一七年六月　Vaswani 等八人` |
| 短句，只记动作 | 笔数极少。一笔是一笔，不修饰，不解释 |
| 互见 | 同一个字可以在不同页面反复出现，这里露一半，那里才看全 |
| 五体 | 内容多时当信息架构：本纪是主线，表是数据，书是专题，列传是人和项目 |
| 平常事也郑重 | 用写大事的规格，写一件小事 |

### 2.2 江苏白话的气味

| 气味 | 画面 | 版面和交互 |
|---|---|---|
| 淡漠 | 不煽情，不夸张 | 标题小而轻，不用感叹号，不做热情的号召按钮 |
| 疏离 | 人物小、隔得远、彼此不对视 | 元素之间隔得开，话说一半就停 |
| 青春期的阵痛 | 小小的不对劲：一个空座、一个转头的人、一个走开的人 | 不给结论 |
| 书生气 | 书、桌、作业、窗 | 宋体、细线、像笔记本的版心 |

结尾停在一个动作或一幅画面上，不总结，不点题。

### 2.3 边界

以上这些约束的是**造字插画和抒情文案**。功能信息照常保留：坐标轴、类别名、单位、图例、流程箭头、操作名称，以及任务本身要求给出的结论和分析。报告该写结论就写，写得短而平。图形已经分得清的类别和操作，按 §3.0 省掉文字。

## 3. 造字法

### 3.0 能不用文字，就不用文字

意思先交给造的字，文字只补图说不全的部分。参照 Anthropic 的两张配图：一条锁链，人就知道大概在讲安全和约束；三个由小到大的圆，人就知道大概是三种模型。

- 要的是三秒内知道大概在讲什么。细节还要紧，再补一行文字，补的是图没说的，不复述图。
- 挑人人都有联想的物：锁链、钥匙、门、一叠纸、一条路。要先解释才懂的比喻，换一个物。
- 造意思用 §3.2 的三种造法：

| 造法 | 怎么表意 | 例子 |
|---|---|---|
| 象形 | 物本身带着意思 | 一条锁链：连着、拴住、防备 |
| 指事 | 形上的差别就是记号 | 三个圆由小到大：三档；其中一个换主色：说的是这一档 |
| 会意 | 两个字放在一起，意思自己出来 | 锁链拴着一个圆：给模型加约束 |

- 每写一行文字先问：盖住它，图还说得明白吗？说得明白就删。
- 默认不写文字：封面、题图、章节头、过场、分享卡片、图标、状态、抒情文案。页面和章节的标题能由图代替时，只留给读屏软件（模板的 `class="sr"`）。
- 这些文字要留：§2.3 的功能信息；数字、人名、引用和出处；任务要求的结论和分析；题记和方印；图形分不开的类别，以及一眼看不出是什么的操作。
- 文章和报告的正文照写，题图和小节图用造的字。讲解类作品能懂优先（§7.7）。
- 图的 `alt`、无字按钮的 `aria-label` 写全这张图的意思，读屏软件和素材加载失败时都读得到。

样字是 `assets/signs/sign_chain.webp`（三笔锁链）和 `sign_three.webp`（三个圆），由代码沿笔触拉成，`sprite.py dye` 可换签。

### 3.1 动笔前先问

这个人此刻在做什么？这件事里什么在动、在变、在等？想清楚再造字。这个问题只决定写什么，不改变写法：**画面里的人和物始终要认得出来**。

### 3.2 三种造法（借汉字六书）

| 造法 | 汉字例子 | 怎么用 | 作品例子 |
|---|---|---|---|
| 象形 | 山、人 | 只抓最简的形，几笔成物 | 两竖一横是一栋楼 |
| 指事 | 「本」是木下加一点 | 用一个点、一个记号指出要害 | 一个颜色不同的点，指出那一个 |
| 会意 | 「信」是人加言 | 两个字放在一起，意思自己出来 | 人加一个向外放射的点，就是唱歌 |

**画它在做什么，不画它长什么样。** 麦克风不必画，声音是一个圆点向四周放射。

### 3.3 字的写法

- 完全平面：没有透视、明暗、投影、场景和写实细节。
- 每一笔是一次刮刀拉过，颜料很厚，看得见脊线和撕裂的干边。
- **人**：一个圆点是头，一笔连续的弧线是整个身子，身子的弯曲说明姿势。腿永远不画，脸永远不画。只有动作非要交代时才加一笔短手。能靠旁边的物件说明的，就不加手。
- **物**：一到三笔，或者用负形（§3.4）。
- 同一作品里，身子的弧度要有变化，不要全是同一个形状。
- 字上不贴标签。看懂要靠字本身；一眼认不出来，就重新造字，不靠文字解释（图表的功能标注见 §2.3）。

### 3.4 负形：物是刮出来的

写物的第二种办法：铺一块厚颜料，用刮刀把物刮掉，露出底下的纸，留下的空白就是那个物。颜料是满的，字是空的。

- **一块**：主色或墨色的厚颜料，大致方形，手抹的不规整，四边撕裂，看得见刮刀的脊线。主色块可以拖进几道墨。
- 主色块每屏最多一块，给最要紧的那一个；平常的负形用墨色块，想多用就用墨色。
- **一到四刀**：一刀是一段空白。空白要宽，边是撕开的毛边，里面什么也没有，透出来的就是纸。
- 不在空白里加白颜料，不在颜料上另画东西。
- 三秒认得出，靠的是空白的形。空白要弯、要撕，不画成教科书图解和图标：DNA 不画梯子的横档。但物的要害不能丢：书弯得像发芽，就重画。
- 只写物和事，不写人。人还是圆点加弧线。
- 主色块就是这一屏的主色。极空时一块摆在大片空白里；极繁时可以做前排被裁切的大块。

样板是 `assets/signs/neg_helix.webp`，一条双螺旋。写新的物，把它当参考图交给图像模型，按 §9.2 逐刀写。

## 4. 两种极端

不要中间状态。

| | 极空 | 极繁 |
|---|---|---|
| 样子 | 一个字，或一行字，大片空白 | 满满一页字，杂而不乱 |
| 来源 | 江苏白话的留白，话说一半 | 《史记》的群像，Alex Webb 的多层构图 |
| 用在 | 界面、封面、幻灯片内容页、章节开头 | 首屏大图、章节过场、作品集主场景 |

**极繁的规则**：按大小分层，前排是被画面裁切的巨大的字，中间中等，后排很小，左、右、前、后、中都有；每一层都在做自己的小事，谁也不看谁；靠节奏和留缝分开，杂而不乱。常常藏一个不一样的人：只有他是主色，或只有他转了头。

界面和正文永远不用极繁，只在信息层级上分层。

## 5. 颜色和纸面

### 5.1 配色

- 每件作品只有**一个主色加墨**。主色从下面的十二支签里抽一支，和内容无关，和上一件不同，题记里写签号（例：`第甲签`）。没有固定的品牌色。
- 主色只给最要紧的那一个：那个人、那个点、那条最高的数据、落款的印。其余全是墨。每屏（网页一个视口、幻灯片一页、一张图）一个；同一对象重复出现算一个。
- 选中用墨，不用主色：一屏常有几个选中，都染色就违背每屏一个。
- 错误用删除线加一句怎么办，成功用一句平话，禁用用斜线底。状态图里的点在出错时可以用主色（§7.4）。
- 多系列数据：最要紧的用主色，其余用墨实心、斜线、空框三种纹理。

| 签 | 色 | 签 | 色 | 签 | 色 | 签 | 色 |
|---|---|---|---|---|---|---|---|
| 甲 | #BE1C1C | 乙 | #4B1F96 | 丙 | #1F3F7A | 丁 | #2B5B3A |
| 戊 | #8A3A00 | 己 | #7A1F5C | 庚 | #0F5C66 | 辛 | #5A4A00 |
| 壬 | #A01840 | 癸 | #334E00 | 子 | #6B2D1E | 丑 | #2A2A8C |

十二支对纸面的对比度都在 5:1 以上。

**色弱（优先于本节和 §7.7）：** 读者里有色弱的人，任何信息都不能只靠颜色传递。分类用直接贴的文字、形状、线型（实线、虚线）、深浅或单字标记；图例也要能不看颜色读懂；说明文字不写「红格」「绿线」。主色只作强调。

唯一的例外是长页导航（§7.6）：它的配色跟着伙伴走，打开时可以有多种颜色，表面有厚度和光照。

`assets/signs/` 的样板字是乙签的紫色。抽到别的签时，样板字只能当参考，字要按新主色重画；负形的颜料块可以直接换签（§9.3）。
- 伙伴的像素形象保留原色，不算主色。
- 底面是微微泛黄的宣纸，看得见纤维和帘纹，所有页面和作品都铺。纸上不再加别的纹理和渐变。
- 网页照 `templates/tokens.css` 铺两张贴图（`assets/paper/` 的 `xuan_fiber`、`xuan_cloud`，multiply 叠加，随页面滚动）。幻灯片、PDF、PPTX、静态图和片头片尾用一整张 `assets/paper/xuan_sheet.webp` 垫底，2560×1440。
- 放在纸上的图和画布都是透明底，不涂底色，不留白块。要盖住后面线条的卡片可以用 `--paper` 平涂。
- 只做浅色。深色系统下照样用浅色纸面。

### 5.2 Token

| token | 值 | 角色 |
|---|---|---|
| `--paper` | #F9F4E8 | 纸色，贴图的底 |
| `--ink` | #211C1C | 标题、要紧的句子、墨色的字 |
| `--ink-2` | #5C5650 | 默认正文 |
| `--ink-3` | #6F6961 | 题记、说明 |
| `--line` | #DDD6C4 | 细线 |
| `--c` | 从十二支签抽 | 主色 |

### 5.3 可读性底线

正文和小字对背景至少 4.5:1，按纸上最深的地方算：`--ink-3` 在那里是 4.52:1，小字不能比它更淡；24px 以上的大字、必要的图形至少 3:1。不达标就换深一点的主色。可读性优先于任何配色。

## 6. 字体

| 用途 | 字体 |
|---|---|
| 中文标题 | 站酷小薇 ZCOOL XiaoWei，字号偏小。小字号糊字时，改用思源宋体 600 |
| 正文 | 思源宋体 Noto Serif SC |
| 普通英文 | Cormorant Garamond 斜体 |
| 公式 | STIX Two Text |
| 题记、代码、标识符、数字 | JetBrains Mono |

优先级：代码和标识符 > 公式 > 数字和编号 > 普通英文 > 中文。中英混排按片段分别用字体。全部来自 Google Fonts，写好回退栈。

### 5.4 厚度

纸是底，纸上除小字以外的东西都有厚度：线是刮刀拉出来的笔触，块是厚颜料，进度是拉笔，按钮是一团颜料，标题和大数字是厚颜料字。正文、日志和小数字保持平的，读得清。

- 平时用真颜料贴图加一点立体边，光是固定的。
- 每屏最多一块实时打光，给最要紧的那一个；要照顾手机的发热和流畅。
- 不做框。分隔靠三种办法：留白加一笔厚颜料；一整块颜料里刮出纸沟，内容住在沟里；大小不同的颜料块错开并被边缘裁切。
- 界面按「现在发生的事」分大小，不做等高等宽的格子：正在发生的占大块，等待的缩成一行，空闲的只剩名字和一个点。

### 6.1 排版：退后

不把要紧的字加粗，把不要紧的字调淡。

- 正文 16.5px，行高 1.9，颜色 `--ink-2`。要紧的句子用 `--ink`，字重不变，每屏不超过两句。
- 段距 1.5em，不缩进，一段不超过三行。
- 标题不超过 1.3rem，靠字距区分层级；四级标题比正文还小。
- 引文放大到 1.12rem，是全节最大的字。列表不用圆点，用小号的序号。
- 链接不变色，下面一条细线。

## 7. 分媒介

| 规则 | 网页、HTML 幻灯片 | 静态图、PDF、PPTX | 视频 |
|---|---|---|---|
| 造字与纸面 | 必做 | 必做 | 片头、片尾、过场 |
| 动效（§8） | 必做 | 不适用 | 按片子节奏 |
| 彩蛋（§10） | 三类 | 只藏在细微处 | 只藏在细微处 |
| 手机宽度 | 必做 | 不适用 | 不适用 |

- 「手机宽度」只约束网页。HTML 幻灯片在手机上整页等比缩放，字号按 1920×1080 画布验收，不横向滚动，并在幻灯片下方显示当前页文字。
- **网页**：开头是题记和一个字，小标题能由字代替就省掉，靠左或错开，不放大图。布局见 §7.1。极繁可以通栏。结尾停在一个字上。手机 390px 不横向滚动。
- **幻灯片**：默认 HTML，1920×1080，安全边距 96px。每页一个字，字说不全才加一句话，或者整页极繁。标题 56px，正文 28px，最小 22px。放不下先拆页。要 PPTX 就给 PPTX，字导出成透明图。
- **数据图**：见 §7.5。
- **文档**：A4，页边 25mm，正文 11pt 思源宋体，行距 1.7；首页或章节开头放一个字。
- **视频**：正片用造字，主色限定为一个主色加墨。片头片尾用造字和本宪法的字体，字幕用思源宋体，伙伴至少出镜一次，藏一个彩蛋。
- **作品集网站**（以后单独开工）：主场景是一页极繁；每件作品是其中一个可以点的字，点开是详情。信息架构用五体。
- 用户指定交付格式时照给，在格式能力内保留造字、配色和字体。

### 7.1 布局：旁批

桌面 5:3 双栏，间隔 80px。正文放左栏，不超过 30rem；右栏放当场核对的账、字和小注。章节之间空 96px。640px 以下并成一栏，旁批紧接对应的正文。

### 7.2 控件：一团抹开

按钮不做矩形框。颜料是 `assets/btn/` 里真画的厚墨，一头圆鼓一头拖尾；CSS 已写在 `templates/page.html`。操作能用造的字说清时，按钮只放这个字，并写好 `aria-label`（§3.0）；一眼看不出的操作照旧写文字。

- 普通按钮：字旁边一小团颜料，字不压在颜料上。
- 主按钮（`class="p"`）和选中项（`aria-pressed="true"`）：颜料抹到字底下，字反白。切换时那一小团长大抹过去。
- 禁用：颜料淡成很小的一点，字退后。
- 按下：颜料略摊开、脊线变平，松手慢慢回来，不弹，字不动。
- 开关（`role="switch"`）：一小团颜料滑过去，打开时变实，旁边写开或关。
- 滑块拇指、勾选仍是实心圆点。输入框和下拉只有一条下划线。
- 触控高度不低于 44px。焦点用 1px 墨色点线外框。

**颜料块按钮**：要一眼看得出能点的地方，比如讲解页的舞台和成组的选项，用一整块厚颜料当按钮。素材是 `assets/btn/` 的 `slab0~3_pale.webp` 和 `slab0~3_ink.webp`，CSS 在 `templates/slab-button.css`，把按钮放进 `.slabs` 容器。

- 平时是一块浅色颜料，字用墨色。
- 主按钮和选中项：墨色颜料从左边抹过来，字反白，像从颜料里刮出来的负形。
- 禁用：颜料变淡，字退后。按下：略压下去。
- 宽度跟着字走，两头的撕边不变形，只拉长中间。方框也可以换成颜料块，比如流程图里的节点。

### 7.3 页面底部：方印

顺序：一个字，字说不全才加一句动作，然后一条细线。细线下左边写上一篇、下一篇、日期和版本、出处，「回到顶部」写成「回到题记」。右下角竖写「你的名字 记」，压一方 2.3rem 的主色小印，印文「肥肥主义」四字，说明这套写法的来处。幻灯片和视频片尾也用。印在的这一屏，主色就给它。

### 7.4 状态：一个点

所有状态都是同一条 1px 的线和同一个 15px 的圆点，不用转圈和骨架屏。点来回走是加载，走到头是成功，停在中间轻跳是保存中，只有线是空，线断了点变主色落下是错误。需要真实进度时另外写数字。文案是一句事实加一句接下来怎么办，不道歉。

### 7.7 讲解类作品：能懂优先

精读论文、教程、讲解这类作品，目的是让人轻松弄懂。取舍的顺序是：能懂 > 适配内容 > 可玩 > 本宪法的风格。

- 开头先讲为什么要解决这个问题，用一个具体场景讲明白，再立刻演出来。
- 图形跟着内容走：流程图、对话记录、表格、时间线、代码卡，哪个讲得清用哪个。造字和一笔人不是必须的，不为风格加插画。需要先解释才懂的比喻不用。
- 每一步配一句话，说清现在发生了什么，图已经说清的不复述（§3.0）。动画要讲明什么东西从哪走到哪，慢到看得清。
- 颜色可以按意思多用几个，比如花掉的和省下的各一种，页面上说清谁代表什么。
- 按钮用颜料块（§7.2），流程图的节点也用颜料块，不画框。条形图平涂，能读准。正文字色加深，舞台里的字不小于 .84rem。手机上导航伙伴缩小，不挡正文。
- 留下的是宣纸、字体、题记、方印、导航扇和平实的语气。

做法见 [jiepou 仓库](https://github.com/chaoRookie/jiepou) 的 `paper-playground` 和 `jiepou` 两个技能。

### 7.6 长页导航：厚涂扇

现成的件在 `templates/nav.html`，贴到页面末尾。章节写成 `<section data-t="章名">`，最多 8 个；章节更多时只给分组写 `data-t`。

- 收起：左下角一只油彩画的像素伙伴，龙娘（东西合璧的白色小龙）、大肥鱼、小肥随机一只，收起后换一只。素材在 `assets/nav/`，每位六帧；小肥封在 `xiaofei.js` 一个文件里，毛色和站姿每次随机。手机上（760px 以下）收起时只从屏幕左边露一小条，留在页边空白里，不盖字；滑动时整只藏起来，按一下才出来。
- 按压：朝屏幕里压平，不是从上往下压扁，也不回弹。沿平常、吃惊、挤眼 > <、摊开、成饼连续变形，帧与帧之间不许跳。
- 打开：从饼继续摊成半径不超过 262px 的扇，中间不停顿。表面沿用饼上的厚涂笔触，实时打光。
- 颜色：从当前这只伙伴身上取，每瓣一个纯色。现实里摊开会混色，这里不混，这是这个导航的那一点不对劲。
- 每瓣写序号和章名。按一瓣先压平再跳章，按扇外或角上收起。
- 动作和配色只开给这个导航，页面其他地方照旧。厚度全页都有（§5.4），实时打光的规则也见 §5.4。

### 7.5 图表：拉笔

横向笔画条，长度严格按数值比例，从零开始，一张图内共用一个量程，准确数字写在行尾。主色只给每张图的最大值。图下配原始表，数字用 JetBrains Mono 右对齐，并注明出处和单位。条差距很小时，以数字为准。

## 8. 动效

- 字的出场是**被抹开**：从一侧揭开，同时轻微位移，约 1.5 秒。不许只有淡入淡出。
- 代码能拉的笔画，可以真的一笔一笔写出来。
- 慢、少。一屏最多一个内容的自动动作（彩蛋伙伴不算）。每个能点的东西都有立刻的反应。
- 缓动用 `smooth`：`t³(10s² + 5st + t²)`，`s = 1 − t`。
- `prefers-reduced-motion` 时不播放自动动画，内容直接显示终态；点击的动画不超过 0.3 秒，伙伴只显示一帧静图。
- 素材加载失败时，文字和数据照常可读；代码拉的笔退回实色矩形。

## 9. 素材怎么来

### 9.1 分工

| 东西 | 谁做 |
|---|---|
| 人、复杂的字、极繁整页、负形的物 | 图像模型按 §9.2 画；agent 验收、抠底 |
| 横竖长笔、数据图、进度、分隔 | 代码用笔触库（`assets/strokes/`）沿路径拉，再染色 |
| 版面、文字、交互 | 代码 |

代码画弯曲的人形目前比较僵硬，默认交给图像模型。

### 9.2 给图像模型的提示词

每个字都由 agent 先想好，把笔画逐条写进提示词，不让模型自己想象画面。固定写上：

```
This is a sign language like newly invented written characters, not a picture.
Completely flat and two-dimensional, no perspective, no shading, no cast shadow, no realism, no face.
Background: perfectly flat uniform pure #00FF00, and the paint contains no green.   （主色是绿色时，这里改成 pure #FF00FF，paint contains no magenta）
Each mark is one single pull of a palette knife loaded with thick oil paint, with visible ridges and torn dry ends.
A person is one round dab for the head plus one continuous curved stroke for the whole body whose bend shows the pose. No legs or feet. At most one short arm stroke, only where asked.
Built only from the marks described, nothing added. Colours: warm ink near-black and <主色> only. No text, letters or numbers.
```

然后逐条写出这张图有哪些笔。

负形（§3.4）换用下面这段。把 `assets/signs/neg_helix.webp` 铺在白底上存成 PNG，作为参考图一起给，并告诉它只学这几点：刀面深浅不一，外缘有缺口，空白弯着拉、宽窄在变，空白穿出边缘。然后逐条写出每一刀：

```
Negative-space form. One single slab of very thick palette-knife oil paint in <主色>, built from many large overlapping knife planes, each plane a clearly different value of that same hue, from a deep shade to a pale tint, the planes meeting in raised ridges. The outer edge of the slab is irregular and torn, wide in some places and bitten in others, never a rounded rectangle. A few short streaks of warm ink near-black #211C1C are dragged into the colour.
The subject exists only as voids scraped all the way through the slab with the knife, showing the same flat background colour through them. Each void is one hand pull of the knife: its width changes along its length, its edge is torn, no ruled straight lines, no perfect circles, not symmetrical. At least one void runs out through the outer edge of the slab and breaks it open there. No painted subject, no raised symbol, no white paint.
Completely flat and two-dimensional, no perspective, no cast shadow. Background: perfectly flat uniform pure #00FF00, and the paint contains no green.   （主色是绿色时，这里改成 pure #FF00FF，paint contains no magenta）
The slab does not touch the image edge. No text, letters or numbers. Colours: <主色> and warm ink near-black only.
```

**不要写**风格形容词（dreamy、impressionist、beautiful 之类）：它们只会把画面拉向模型见得最多的平均样子。

### 9.3 验收

- 字有没有多画东西，人有没有长出腿和脸。
- 三秒内认得出是什么；盖住所有文字，还说得出这张图大概在讲什么（§3.0）。
- 看着像公共标识或奥运图标，就减笔，重画。
- 负形：物是不是空白而不是画上去的；抠底以后空白里透出来的是不是纸；刀面有没有深浅；空白有没有穿出边缘。
- 要动的东西画成 5×5 共 25 帧雪碧图（主体内部的变形才逐帧；移动、旋转、揭开用代码）。
- 处理：`scripts/sprite.py`（需要 Pillow 和 NumPy）抠底、切帧、压 WebP；品红幕布加 `--screen magenta`。
- 上色：模型画的颜色会偏。负形抠底以后一律过一遍 `python3 scripts/sprite.py dye 原图.webp 输出.webp --color '#BE1C1C'`，颜色就准了，也能换成任何一支签，脊线和墨都留着。线条细的字不换，按新主色重画（§5.1）。

## 10. 彩蛋与伙伴

伙伴：白龙 `ψ(◦ ◦)ψ∿∿`（东西合璧的白色长尾龙）、大肥鱼（蓝色）。像素形象，雪碧图在 `assets/partners/`；大肥鱼目前只有 `assets/nav/` 的六帧。可以换成你自己的伙伴。

小肥 `(๑•ㅅ•๑)` 是这套写法的作者的形象：一只圆滚滚的肥仓鼠，只用油彩画，不做像素。腮帮是两个纯圆，鼓鼓的，表面只有毛。毛色金白、墨白两种随机；平时捧手和啃瓜子随机，啃瓜子时中间一大颗门牙真的咬在杏仁一样大的瓜子上；走路（比如被拖动）用侧身。它只待在长页导航（§7.6）里，不进彩蛋的探头轮换。

伙伴只在彩蛋和长页导航（§7.6）里出现，正文和数据图里不放。彩蛋三类：

1. **小概率**：约 30 次打开有 1 次路过，可用 `#longlong` 锚点直接看。
2. **加载、空页面、出错**：伙伴探头。谁来探头不固定，有 25 帧素材的轮着来。
3. **藏在细微处**：点某个字三下有伙伴探头；点落款的印三下也是；极繁里藏一个现代的小东西。

所有伙伴共用一个出场位，一屏最多一只。优先级：出错 > 加载和空页面 > 点出来的 > 小概率路过。高的顶掉低的，同级忽略新来的。空页面的伙伴在内容出现时退场。

## 11. agent 守则

1. 做任何视觉产出前，先读本文件和 `SKILL.md`。
2. 模板是起点，用了模板也要按 §12 验收。
3. 交付时附自查，逐项写「已实测 / 只静态检查 / 不适用」，写明有意偏离及理由。
4. 代码里不写注释。

## 12. 自查清单

通用：
- [ ] 画面是造字：平面、笔数少、厚涂，没有写实的人和物（讲解类作品按 §7.7，图形跟着内容走）
- [ ] 人和物三秒认得出
- [ ] 能不用文字的地方都没用：盖住文字还说得出大概在讲什么；无字的图和按钮都有 `alt` 或 `aria-label`（§3.0）
- [ ] 只有一个主色加墨，每屏主色只给最要紧的一个（伙伴除外）
- [ ] 字上不贴标签；抒情文案不总结不点题；没有感叹号和口号；功能信息和任务要求的结论都在（§2.3）
- [ ] 有题记
- [ ] 底面是宣纸，图和画布透明，没有白块
- [ ] 极空或极繁，没有不上不下的中间状态；没有等高等宽的平均格子（§5.4）
- [ ] 除小字外都有厚度，没有框，分隔清楚（§5.4）
- [ ] 可读性达标
- [ ] 主色来自十二支签，题记写了签号
- [ ] 不看颜色也能读懂：分类靠文字、形状、线型、深浅或单字标记
- [ ] 字体按 §6，排版按 §6.1
- [ ] 数字可追溯，示意已标注，引用写明出处
- [ ] 代码没有注释

网页、HTML 幻灯片另加：
- [ ] 布局、控件、页面底部、状态、图表分别按 §7.1 到 §7.5；长页用 §7.6 的导航
- [ ] 字的出场有抹开，不只淡入淡出
- [ ] 网页 390px 宽不横向滚动；幻灯片手机上有当前页文字
- [ ] 减少动态模式生效；素材缺失时文字可读
- [ ] 三类彩蛋都有，出场位规则生效

幻灯片另加：
- [ ] 每页一个字，字说不全才加一句话，或整页极繁；字号不低于最小值

视频另加：
- [ ] 主色限定；片头片尾用造字；字幕用思源宋体；伙伴出镜；藏了一个彩蛋
